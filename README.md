# Consulta SQL Avançado

Repositório de apoio à disciplina Consulta SQL Avançado, 
do curso de Sistemas de Informação – Graduação.

Este repositório reúne os materiais utilizados ao longo do semestre, servindo como base para o estudo da linguagem SQL com foco em boas práticas e no processo analítico de dados.

---

# 🎯 Sobre a disciplina

A disciplina tem como objetivo desenvolver a capacidade de elaborar consultas SQL avançadas para recuperação, transformação e análise de dados em bancos de dados relacionais.

Durante o semestre serão exploradas técnicas modernas da linguagem SQL utilizadas em ambientes corporativos, com foco em:

* Extração de informações;
* Combinação de dados provenientes de múltiplas tabelas;
* Agregação e sumarização;
* Construção de indicadores;
* Consultas analíticas;
* Geração de relatórios;
* Boas práticas de desempenho e organização do código SQL.

Toda a disciplina será conduzida de forma prática, utilizando estudos de caso e bases de dados reais.

---

# 🧠 Objetivos de Aprendizagem

Ao final da disciplina o estudante será capaz de:

* compreender a estrutura lógica de bancos de dados relacionais;
* construir consultas SQL para diferentes cenários;
* utilizar funções e expressões SQL;
* combinar informações através de JOINs;
* elaborar subconsultas e CTEs;
* produzir consultas voltadas à geração de indicadores;
* interpretar resultados e validar informações;
* escrever consultas organizadas, eficientes e de fácil manutenção.
